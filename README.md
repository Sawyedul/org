# Sawyedul Amin — Personal Portfolio

A responsive one-page personal website inspired by the editorial/storytelling structure of arf at khan.com, but written and designed as an original portfolio for Sawyedul Amin.

## Files
- index.html — website content
- style.css — responsive design
- script.js — mobile menu and current year

## Before publishing
1. Replace the `YOUR PHOTO` placeholder in `index.html` with your own portrait.
2. Replace `YOUR-EMAIL@example.com` with your preferred public email.
3. Add your social-media links if desired.
4. Upload the three files to your hosting provider.

The site is intentionally static, so it can be hosted cheaply or on many free static-hosting services.
